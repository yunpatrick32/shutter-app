## 6. Geo-ads Spec — Updates Folded In (see also `geo_ads_campaign_spec.md`)

Three updates from Apr 28 → ad spec:

1. **Legal Apr 28 conditions** added as a creative-review checklist, in-spec:
   - **No ®** on either "Shutter" or "Shutter Find LLC" mark in any ad creative until USPTO certificate issues. Using ® on an unregistered mark is a §43(a) Lanham Act violation.
   - **™ permitted** on either mark to assert common-law rights. Use sparingly — once per ad, not on every mention.
   - **No comparative or superlative claims.** Ban list: "America's #1," "the best," "more than [competitor]," named comparisons against Shutterfly / Splacer / Bookalook / Thumbtack. FTC § 5 risk.
   - **Creator-feature consent.** Any ad creative that names or shows a real (non-Patrick) creator requires written consent. Standing recommendation: add a one-line model release to the join-flow signup screen as a checkbox: *"I allow Shutter Find LLC to feature my profile in promotional material until I opt out via DM."* Plus a P.S. in outreach DM templates 1–4. **Action:** Patrick updates the join flow when Dev next ships UI; in the meantime, get a written "yes" via DM before featuring any creator in an ad. Save the screenshot.

2. **CA SB-478 fee-disclosure precondition** (NEW). Marketing recommends folding into the launch gate:
   - **Old gate (5):** custom domain live + 15 real creators + pixel installed + Legal mark-use sign-off + Stripe webhook deployed.
   - **NEW gate (6):** + **SB-478 verified** = Dev confirms via test-mode-checkout screenshot that the 8% service fee renders as a discrete line in the booking confirmation UI. Stripe Checkout's default `application_fee_amount` rendering almost certainly already itemizes; verification is 5 minutes of Dev work + Legal sign-off.
   - **Why:** SB-478 ("Honest Pricing Law") imposes up to $1,000-per-violation fines under CA Civ. Code § 1770.1 if mandatory fees aren't disclosed in the advertised price. A geo-ad in California that drives a checkout failing SB-478 is theoretical exposure. Cheap to verify, dumb not to.
